# Phase 22 - Watch Window

## 相依階段

- Phase 09
- Phase 21

## 目標

建立指定 Address 的持續監控頁面。

## 欄位

- Key
- Address
- Type
- Previous Value
- Current Value
- Delta
- Last Update
- Status

## 功能

- Add / Remove
- Pause / Resume
- Batch refresh
- Refresh interval
- Mark unreadable

## 預設更新頻率

- 250 ms
- 500 ms
- 1000 ms
- Custom

## 驗收標準

- Process 結束後自動停止。
- 單一 Address 讀取失敗不影響其他項目。
